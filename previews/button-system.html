Proposed

One button, taken from .pg-btn because most pages already use it: 16px bold, fully rounded, 58px tall. Every colourway has a 1px border (transparent on filled ones), so filled and outlined buttons are the same height. Filled buttons fade on hover; the outlined one fills black. A small size keeps the header button at its current 42px.

For you to decide

  1. Header button size. The proposal uses the small size so the header row doesn’t change height. The alternative is the full 58px size everywhere, which makes the header row taller.
  2. Hover. Filled buttons fade and the outlined one fills black, as .pg-btn does now. An alternative is that every button fills black on hover, with white text.
  3. Filter pills and tags stay as they are. They are a separate component and aren’t part of this change.
